# 黑胶唱片悬浮播放器

## 项目概述

基于原有的悬浮播放器项目改造，采用黑胶唱片外观设计。

## 功能特性

### 悬浮球状态
- 黑胶唱片外观（黑色圆形 + 唱片纹理）
- 播放时持续旋转，暂停时停止旋转
- 可拖动定位
- 双击展开随身听面板

### 随身听面板（展开状态）
- 白色背景，类似网易云音乐随身听风格
- 黑胶唱片组件：
  - 黑色唱片带旋转动画
  - 顶针效果：暂停时抬起/移开，播放时接触唱片并随唱片旋转
- 歌曲信息显示：歌名 + 歌手
- 进度条：显示当前时间/总时长，可拖动调整
- 控制按钮：
  - 播放/暂停
  - 上一首/下一首
  - 随机播放（切换）
  - 循环模式（列表循环/单曲循环/关闭）
  - 播放列表
- 自动收缩：5秒无操作自动收起

### 动态背景效果
- 展开面板时可显示雪花/气泡粒子效果
- 可通过 `showParticles` 开关控制

## 技术要点

### input[type=range] 样式保护
为防止全局样式污染，所有 range 相关样式必须使用 `!important` 强制重置：
- `appearance: none`
- `background: transparent`
- `filter: none`
- `border-radius: 0`

### 响应式设计
- 桌面端：完整随身听面板（320px宽）
- 移动端：自适应缩小（280px/260px宽）

## 交互逻辑（保留原有逻辑）

1. **拖拽**：支持鼠标和触摸拖动，拖动时保存位置到 localStorage
2. **展开/收缩**：双击悬浮球展开，5秒无操作自动收缩
3. **播放控制**：播放/暂停/切歌/随机/循环/列表功能完整保留
4. **歌词解析**：保留原有 LRC 歌词解析和显示逻辑
5. **歌曲搜索**：使用原有 Music API 进行搜索和缓存

## 使用方式

1. 确保酒馆中包含 `<bgm>歌曲名 - 歌手</bgm>` 格式的标签
2. 加载脚本后，悬浮球会自动显示
3. 双击悬浮球打开随身听面板
4. 点击播放按钮开始播放
